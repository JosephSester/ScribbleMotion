# Scribble Motion

Draw your own cartoons, frame by frame. A free home-screen web app for iPhone, iPad, and Android:
draw on the canvas, save frames, trace over the see-through ghost of the last frame (onion skin),
then press play and watch it move. Layers, brushes, fill bucket, lasso transform, symmetry guides,
photo and camera frames, voice/music/sound effects, and export to video or GIF. Works offline;
all data stays on the device.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173/ScribbleMotion/
```

Pushing to `main` deploys to https://josephsester.github.io/ScribbleMotion/.

## Install on a phone

Open the link above in Safari (iPhone/iPad) → Share → **Add to Home Screen**.
On Android, open it in Chrome → menu → **Add to Home screen** / **Install app**.
